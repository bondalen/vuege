#### 1. Проблема длины строк ✅ РЕШЕНО

**Причина**: Колонка `oafNum` содержала значения длиной до 597 символов  
**Решение**: Использование типа `text` вместо `varchar(100)`  
**Результат**: ✅ Таблица `ogAgFeeGr` успешно мигрирована (1178 записей)

#### 2. Проблемы с несуществующими колонками ✅ РЕШЕНО

**Причина**: Таблицы ссылались на несуществующие колонки в SQL Server  
**Решение**: Миграция только с существующими колонками  
**Результат**: ✅ Все проблемные таблицы успешно мигрированы
