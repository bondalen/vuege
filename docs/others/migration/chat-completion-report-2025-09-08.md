### **Для очистки HTML:**
```sql
-- Функция для очистки HTML
CREATE OR REPLACE FUNCTION clean_html(input_text TEXT) 
RETURNS TEXT AS $$
BEGIN
    RETURN regexp_replace(input_text, '<[^>]*>', '', 'g');
END;
$$ LANGUAGE plpgsql;
```
