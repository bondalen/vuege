## 🔧 Ключевые особенности системы типов

### **Двойная система эквивалентов:**

#### **Базовый эквивалент** (`mssql_base_types.postgres_equivalent_type`):
- **Цель**: Быстрый поиск и общее планирование
- **Примеры**: `nvarchar` → `varchar`, `int` → `integer`
- **Использование**: Общая оценка сложности миграции

#### **Детальная связь** (`mssql_derived_types` ↔ `postgres_derived_types`):
- **Цель**: Точный маппинг с параметрами
- **Примеры**: `nvarchar(255)` → `varchar(255)`, `nvarchar(max)` → `text`
- **Использование**: Точное выполнение миграции

### **Обработка исключений:**
- **`nvarchar(max)` → `text`**: Специальный случай для неограниченной длины
- **`money` → `numeric(19,4)`**: Стандартизация денежных типов
- **`varchar(1)` → `char(1)`**: Анализ фиксированной длины
