# Правила именования таблиц в PostgreSQL

## 🎯 **ОСНОВНЫЕ ПРАВИЛА ИМЕНОВАНИЯ**

### **📋 Допустимые символы в названиях таблиц PostgreSQL:**

#### **1. Без кавычек (рекомендуемый способ):**
- **Первый символ**: Буква (a-z, A-Z) или подчеркивание (_)
- **Последующие символы**: Буквы, цифры (0-9), подчеркивания (_)
- **НЕ рекомендуется**: Знак доллара ($) - снижает переносимость

#### **2. В двойных кавычках (специальные случаи):**
- **Любые символы**: Кроме символа с кодом 0
- **Включает**: Пробелы, специальные символы, разный регистр
- **Ограничение**: При обращении всегда нужны двойные кавычки

## ✅ **РЕКОМЕНДУЕМЫЕ ПРАКТИКИ**

### **🎯 Лучшие практики именования:**
1. **Нижний регистр**: `user_accounts` вместо `UserAccounts`
2. **Подчеркивания**: `order_items` вместо `orderItems`
3. **Без пробелов**: `product_catalog` вместо `product catalog`
4. **Без специальных символов**: `user_data` вместо `user-data`
5. **Описательные имена**: `customer_orders` вместо `co`

### **📏 Ограничения длины:**
- **Максимум**: 63 символа (ограничение PostgreSQL)
- **Рекомендуется**: До 30-40 символов для удобства

## 🚫 **ЗАПРЕЩЕННЫЕ И ЗАТРУДНИТЕЛЬНЫЕ СИМВОЛЫ**

### **❌ Полностью запрещенные:**
- **Символ с кодом 0**: Нулевой байт
- **Ключевые слова**: `SELECT`, `FROM`, `WHERE` и т.д.

### **⚠️ Не рекомендуется:**
- **Знак доллара ($)**: `table$name` - проблемы с переносимостью
- **Дефис (-)**: `table-name` - требует кавычек
- **Пробелы**: `table name` - требует кавычек
- **Специальные символы**: `@`, `#`, `%`, `&` и т.д.

## 🛠️ **ПРАКТИЧЕСКИЕ РЕКОМЕНДАЦИИ ДЛЯ МИГРАЦИИ**

### **🎯 Стратегия именования для проекта Vuege:**

#### **1. Базовые правила:**
- **Сохранить структуру**: `cnInvAccnt` → `cn_inv_accnt`
- **Добавить подчеркивания**: Для разделения слов
- **Нижний регистр**: Для соответствия PostgreSQL конвенциям
- **Сохранить смысл**: Не менять логику именования

#### **2. Обработка длинных имен:**
- **Разбить на части**: `cnInvAccntSmpl` → `cn_inv_accnt_smpl`
- **Сократить при необходимости**: `cn_inv_accnt_smpl` → `cn_inv_acc_smpl`
- **Документировать изменения**: В системе контроля миграции

#### **3. Специальные случаи:**
- **Ключевые слова**: Обернуть в кавычки или переименовать
- **Специальные символы**: Заменить на подчеркивания
- **Пробелы**: Заменить на подчеркивания

## 🔧 **SQL ДЛЯ ПРЕОБРАЗОВАНИЯ ИМЕН**

### **Функция преобразования имен:**
```sql
CREATE OR REPLACE FUNCTION mcl.convert_table_name(mssql_name text)
RETURNS text AS $$
BEGIN
    -- Добавляем подчеркивания перед заглавными буквами
    -- cnInvAccnt → cn_inv_accnt
    RETURN lower(
        regexp_replace(
            mssql_name,
            '([a-z])([A-Z])',
            '\1_\2',
            'g'
        )
    );
END;
$$ LANGUAGE plpgsql;
```

### **Пример использования:**
```sql
-- Тестирование функции
SELECT 
    'cnInvAccnt' as original,
    mcl.convert_table_name('cnInvAccnt') as converted;
-- Результат: cn_inv_accnt
```
