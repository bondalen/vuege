## 🔧 Исправленные проблемы

### ❌ Проблема с типами данных:
- **Ошибка:** `VARCHAR(-1)` в SQL Server (означает MAX)
- **Решение:** Автоматическая замена на `TEXT` в PostgreSQL
- **Результат:** Все таблицы созданы без ошибок

### 📋 Исправленная конвертация типов:
```python
def convert_data_type(self, mssql_type, max_length, precision, scale):
    # Обработка случая VARCHAR(-1) - заменяем на TEXT
    if mssql_type.lower() in ['varchar', 'nvarchar', 'char', 'nchar'] and max_length == '-1':
        return 'TEXT'
```
