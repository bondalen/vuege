## 📋 **НАЗНАЧЕНИЕ ТРИГГЕРА**

### **🎯 Основная функция:**
Контролирует **уникальность связи между исходной таблицей и проблемой** в системе контроля миграции MS SQL → PostgreSQL.

### **🔧 Логика работы:**
- **Одна таблица** не должна быть связана с **одной проблемой** дважды
- **Даже разными способами решения** (через промежуточную таблицу `problems_tb_slt_mp`)
- **Промежуточная таблица** связывает таблицы со способами решения
- **Через способ решения** определяется проблема

### **🏗️ Архитектура связей:**
```
mcl.mssql_tables (исходные таблицы)
    ↓ table_id
mcl.problems_tb_slt_mp (связи)
    ↓ solution_id  
mcl.problems_tb_slt (способы решения)
    ↓ problem_id
mcl.problems_tb (проблемы)
```

## 🔧 **СОЗДАННАЯ ФУНКЦИЯ**

### **📝 Код функции с комментариями:**
```sql
-- ===================================================================
-- Функция: mcl.check_table_problem_uniqueness()
-- ===================================================================
-- НАЗНАЧЕНИЕ:
-- Контролирует уникальность связи между исходной таблицей и проблемой
-- в системе контроля миграции MS SQL → PostgreSQL
--
-- ПРОБЛЕМА:
-- Одна исходная таблица не должна быть связана с одной проблемой дважды,
-- даже если используются разные способы решения этой проблемы
--
-- АРХИТЕКТУРА СВЯЗЕЙ:
-- mcl.mssql_tables (исходные таблицы)
--     ↓ table_id
-- mcl.problems_tb_slt_mp (связи)
--     ↓ solution_id  
-- mcl.problems_tb_slt (способы решения)
--     ↓ problem_id
-- mcl.problems_tb (проблемы)
--
-- ПРИМЕР:
-- Таблица 'cnInv' связана с проблемой 'заглавные буквы' через способ 'не определен'
-- Попытка связать ту же таблицу с той же проблемой через другой способ должна быть заблокирована
--
-- АВТОР: AI Assistant
-- ДАТА: 6 сентября 2025
-- ВЕРСИЯ: 1.0
-- ===================================================================

CREATE OR REPLACE FUNCTION mcl.check_table_problem_uniqueness()
RETURNS TRIGGER AS $$
DECLARE
    problem_id_val INTEGER;
    table_name_val VARCHAR(255);
    problem_name_val VARCHAR(255);
BEGIN
    -- Получение ID проблемы из способа решения
    SELECT problem_id INTO problem_id_val
    FROM mcl.problems_tb_slt 
    WHERE id = NEW.solution_id;
    
    -- Получение имен для информативного сообщения об ошибке
    SELECT object_name INTO table_name_val
    FROM mcl.mssql_tables 
    WHERE id = NEW.table_id;
    
    SELECT problem_name INTO problem_name_val
    FROM mcl.problems_tb 
    WHERE id = problem_id_val;
    
    -- Проверка уникальности связи таблица-проблема
    -- Ищем существующие связи между той же таблицей и той же проблемой
    IF EXISTS (
        SELECT 1 
        FROM mcl.problems_tb_slt_mp mp
        INNER JOIN mcl.problems_tb_slt s ON mp.solution_id = s.id
        WHERE mp.table_id = NEW.table_id 
        AND s.problem_id = problem_id_val
        AND mp.id != COALESCE(NEW.id, 0)  -- Исключаем текущую запись при UPDATE
    ) THEN
        RAISE EXCEPTION 'ОШИБКА УНИКАЛЬНОСТИ: Таблица ''%'' (ID: %) уже связана с проблемой ''%'' (ID: %). Одна таблица не может быть связана с одной проблемой дважды, даже разными способами решения.', 
            table_name_val, NEW.table_id, problem_name_val, problem_id_val;
    END IF;
    
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;
```

## 🔧 **СОЗДАННЫЙ ТРИГГЕР**

### **📝 Код триггера с комментариями:**
```sql
-- ===================================================================
-- Триггер: trigger_check_table_problem_uniqueness
-- ===================================================================
-- НАЗНАЧЕНИЕ:
-- Автоматически вызывает функцию check_table_problem_uniqueness()
-- при попытке INSERT или UPDATE записей в таблице mcl.problems_tb_slt_mp
--
-- СЦЕНАРИИ СРАБАТЫВАНИЯ:
-- 1. INSERT - при создании новой связи таблица-способ решения
-- 2. UPDATE - при изменении существующей связи
--
-- ЦЕЛЬ:
-- Предотвратить дублирование связей между таблицами и проблемами
-- в системе контроля миграции
--
-- АВТОР: AI Assistant
-- ДАТА: 6 сентября 2025
-- ВЕРСИЯ: 1.0
-- ===================================================================

CREATE TRIGGER trigger_check_table_problem_uniqueness
    BEFORE INSERT OR UPDATE ON mcl.problems_tb_slt_mp
    FOR EACH ROW
    EXECUTE FUNCTION mcl.check_table_problem_uniqueness();
```
