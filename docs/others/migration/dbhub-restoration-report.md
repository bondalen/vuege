## 🚀 Возможности DBHub для миграции

### **Доступные инструменты:**
- `execute_sql` - выполнение SQL запросов
- `generate_sql` - генерация SQL запросов
- `explain_db` - анализ структуры базы данных

### **Преимущества для миграции:**
1. **Автоматическое определение** структуры таблиц
2. **Динамическая генерация** SQL запросов
3. **Валидация данных** в реальном времени
4. **Обработка ошибок** и восстановление
5. **Пакетная обработка** больших объемов данных

### **Примеры использования:**
```python
# Анализ структуры таблицы
structure = dbhub.explain_db("ags.st")

# Выполнение миграции
result = dbhub.execute_sql("SELECT * FROM ags.st LIMIT 5")

# Генерация INSERT запросов
insert_sql = dbhub.generate_sql("INSERT INTO ags.st")
```
