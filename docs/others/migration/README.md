# 📊 Документация миграции базы данных

Эта папка содержит полную документацию процесса миграции схемы AGS из SQL Server в PostgreSQL.

## 🎯 Обзор миграции

**Цель**: Миграция схемы `ags` из базы данных SQL Server `Fish_Eye` в базу данных PostgreSQL `Fish_Eye`
**Результат**: 236/251 таблиц успешно мигрировано (94.0%)
**Объем данных**: ~1,800,000+ записей
**Статус**: Завершена с отличными результатами

### 🗄️ Базы данных миграции:
- **Источник**: SQL Server 2022 Express, база данных `Fish_Eye`, схема `ags`
- **Цель**: PostgreSQL 16, база данных `Fish_Eye`, схема `ags` (для данных) + схема `mcl` (для контроля)
- **Система контроля**: Полностью реализована в схеме `mcl` с 26 таблицами для отслеживания процесса миграции
