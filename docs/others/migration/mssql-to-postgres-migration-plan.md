# План миграции схемы ags из SQL Server в PostgreSQL

## 📋 Обзор

Данный документ описывает план миграции схемы `ags` из базы данных `Fish_Eye` (SQL Server) в базу данных `vuege` (PostgreSQL).

## 🎯 Цели миграции

1. **Перенос структуры данных**: Создание таблиц в PostgreSQL с правильными типами данных
2. **Перенос данных**: Копирование всех данных из SQL Server в PostgreSQL
3. **Сохранение целостности**: Поддержка первичных ключей, внешних ключей и индексов
4. **Валидация**: Проверка корректности переноса данных

## 📊 Анализ исходной базы данных

### Статистика схемы ags:
- **Количество таблиц**: 166
- **Источник**: SQL Server 2022 Express
- **База данных**: Fish_Eye
- **Схема**: ags

### Основные группы таблиц:
1. **Контракты (cn_*)**: Таблицы для работы с контрактами
2. **Инвестиции (inv_*)**: Таблицы для инвестиционных данных
3. **Организации (org_*)**: Таблицы организаций
4. **Налоговые данные (rgTax_*)**: Налоговая информация
5. **Документы (JuUnDoc_*)**: Юридические документы
6. **Импорт данных (import_*)**: Таблицы для импорта

## 🛠️ Инструменты миграции

### Созданные скрипты:
1. **`analyze-mssql-schema.sql`** - Анализ структуры SQL Server
2. **`mssql-to-postgres-migration.py`** - Основной скрипт миграции
3. **`run-migration.sh`** - Скрипт запуска миграции
4. **`requirements-migration.txt`** - Зависимости Python

### Требования:
- Python 3.7+
- pyodbc (для подключения к SQL Server)
- psycopg2-binary (для подключения к PostgreSQL)
- ODBC Driver 18 for SQL Server

## 🚀 Инструкции по запуску

### 1. Установка зависимостей:
```bash
cd /home/alex/vuege/scripts
pip3 install -r requirements-migration.txt
```

### 2. Проверка подключений:
```bash
# SQL Server
docker exec vuege-mssql /opt/mssql-tools18/bin/sqlcmd -S localhost -U sa -P Vuege2024! -C -Q "SELECT 1"

# PostgreSQL
docker exec postgres-java-universal psql -U postgres -d vuege -c "SELECT 1;"
```

### 3. Запуск миграции:
```bash
cd /home/alex/vuege/scripts
./run-migration.sh
```

## ⚠️ Риски и ограничения

### Потенциальные проблемы:
1. **Большие объемы данных** - Некоторые таблицы могут содержать миллионы записей
2. **Специфичные типы данных** - Некоторые типы SQL Server могут не иметь прямых аналогов
3. **Сложные ограничения** - Внешние ключи и проверки могут требовать особого внимания
4. **Производительность** - Миграция может занять значительное время

### Меры предосторожности:
1. **Резервное копирование** - Создание бэкапа PostgreSQL перед миграцией
2. **Поэтапная миграция** - Миграция таблиц группами
3. **Валидация** - Проверка данных после каждого этапа
4. **Откат** - Возможность отката изменений
