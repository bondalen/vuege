## 🛠️ Инструменты

### **PlantUML**
```bash
# Установка
sudo apt-get install plantuml

# Генерация изображений
plantuml *.puml
plantuml -tsvg *.puml
```

### **Mermaid**
```bash
# Установка
npm install -g @mermaid-js/mermaid-cli

# Генерация изображений
mmdc -i input.mmd -o output.png
```
