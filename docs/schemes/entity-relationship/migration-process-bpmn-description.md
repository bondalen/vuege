# 🔄 BPMN Описание процесса миграции базы данных

## 📋 **BPMN Элементы процесса:**

### **🎯 Start Event (Начальное событие):**
- **Тип**: None Start Event
- **Описание**: Начало процесса миграции базы данных

### **📝 Activities (Действия):**

#### **1. Подготовительные действия:**
- **Создание запроса для получения списка таблиц исходной БД**
  - **Тип**: Service Task
  - **Исполнитель**: Система
  - **Результат**: Список таблиц MS SQL Server

#### **2. Заполнение системы контроля:**
- **Заполнение системы контроля данными о исходных таблицах**
  - **Тип**: Service Task
  - **Исполнитель**: Система
  - **Результат**: Таблица mcl.mssql_tables

- **Заполнение системы контроля данными о исходных типах данных**
  - **Тип**: Service Task
  - **Исполнитель**: Система
  - **Результат**: Таблицы типов данных

- **Заполнение системы контроля данными о полях исходных таблиц**
  - **Тип**: Service Task
  - **Исполнитель**: Система
  - **Результат**: Таблица mcl.mssql_columns

#### **3. Оптимизация и анализ:**
- **Оптимизация поля описаний колонок**
  - **Тип**: Service Task
  - **Исполнитель**: Система
  - **Результат**: Обновленная структура

- **Определение аналогов Postgres для исходных типов данных**
  - **Тип**: Service Task
  - **Исполнитель**: Система
  - **Результат**: Таблицы типов PostgreSQL

#### **4. Создание целевых объектов:**
- **Создание аналогов таблиц без объектов таблиц**
  - **Тип**: Service Task
  - **Исполнитель**: Система
  - **Результат**: Таблица mcl.postgres_tables

- **Создание аналогов колонок таблиц**
  - **Тип**: Service Task
  - **Исполнитель**: Система
  - **Результат**: Таблица mcl.postgres_columns

- **Создание аналогов ключей, индексов, ограничений**
  - **Тип**: Service Task
  - **Исполнитель**: Система
  - **Результат**: Таблицы ключей, индексов, ограничений

#### **5. Анализ дополнительных компонентов:**
- **Анализ необходимости дополнительных компонентов миграции**
  - **Тип**: Service Task
  - **Исполнитель**: Система
  - **Результат**: Рекомендации по партиционированию, полнотекстовому поиску

#### **6. Финальный этап:**
- **Последовательный перенос таблиц на основе системы контроля**
  - **Тип**: Service Task
  - **Исполнитель**: Система
  - **Результат**: Полностью мигрированная база данных

### **🔚 End Event (Конечное событие):**
- **Тип**: None End Event
- **Описание**: Завершение процесса миграции

## 🔄 **Поток выполнения (Sequence Flow):**

```
Start → Создание запроса → Заполнение таблиц → Заполнение типов → 
Заполнение полей → Оптимизация → Определение аналогов → 
Создание таблиц → Создание колонок → Создание ключей → 
Анализ компонентов → Перенос таблиц → End
```

## 📊 **Gateways (Шлюзы):**

### **Parallel Gateway (Параллельный шлюз):**
- **После**: "Заполнение системы контроля данными о полях исходных таблиц"
- **Назначение**: Параллельное выполнение оптимизации и определения аналогов

### **Exclusive Gateway (Исключающий шлюз):**
- **После**: "Анализ необходимости дополнительных компонентов миграции"
- **Назначение**: Выбор стратегии миграции на основе анализа

## 🎯 **Lanes (Дорожки):**

### **Lane 1: Система контроля миграции**
- Заполнение исходных данных
- Создание целевых объектов
- Анализ компонентов

### **Lane 2: База данных PostgreSQL**
- Создание объектов
- Валидация миграции
- Мониторинг процесса

## 📋 **Data Objects (Объекты данных):**

- **mcl.mssql_tables** - Исходные таблицы
- **mcl.mssql_columns** - Исходные колонки
- **mcl.postgres_tables** - Целевые таблицы
- **mcl.postgres_columns** - Целевые колонки
- **DDL Scripts** - Скрипты создания
- **Migration Status** - Статус миграции
