# Диаграммы сущность-связь системы контроля миграции

**Дата создания:** 31 августа 2025  
**Статус:** Активные  
**Версия:** 1.0

## 📋 Описание

Данная папка содержит PlantUML диаграммы сущность-связь для системы контроля миграции объектов MS SQL Server в PostgreSQL.

## 🗄️ Файлы схем

### 1. **migration-control-system-schema.puml**
Основная схема данных системы контроля миграции с использованием наследования таблиц.

**Содержит:**
- Родительская таблица `mssql_objects` и дочерние таблицы MS SQL
- Родительская таблица `postgres_objects` и дочерние таблицы PostgreSQL
- **Система типов данных:** Родительская таблица `mssql_data_types` с дочерними `mssql_base_types` и `mssql_derived_types`
- Таблица задач миграции `migration_tasks`
- Таблицы колонок: `mssql_columns` и `postgres_columns`
- Связи между объектами MS SQL и PostgreSQL с обязательными и уникальными внешними ключами
- Представления для анализа: `migration_overview`, `table_migration_details`, `view_migration_details`, `data_type_migration_summary`
- Индексы и ограничения для обеспечения целостности данных

**Особенности:**
- Каждый объект PostgreSQL имеет обязательный и уникальный внешний ключ на соответствующий объект MS SQL
- Исключает появление в целевой БД объектов, не соответствующих исходным
- Исключает дублирование объектов в целевой БД
- **Система типов данных MS SQL:** Позволяет отслеживать все типы полей с их параметрами для корректного маппинга в PostgreSQL
- **Система типов данных PostgreSQL:** Аналогичная система для типов данных в PostgreSQL с связями один-к-одному с MS SQL типами
- **Связи типов данных:** Каждый тип PostgreSQL имеет обязательную и уникальную связь с соответствующим типом MS SQL

### 2. **migration-functions-schema.puml**
Схема функций и триггеров для работы с системой контроля миграции.

**Содержит:**
- Функции для добавления объектов: `add_mssql_table()`, `add_mssql_view()`
- Функции для обновления статусов: `update_migration_status()`
- Функции для получения отчетов: `get_migration_progress()`
- Триггеры: `update_updated_at()`, `validate_object_name()`
- Связи функций с таблицами

### 3. **migration-process-flow.puml**
Основная диаграмма процесса миграции объектов с использованием подпроцессов.

**Содержит:**
- Начало процесса миграции
- Создание задачи миграции
- Подпроцесс "Перенос таблиц" (детализация в отдельной диаграмме)
- Генерация отчетов
- Завершение процесса

**Примечание:** 
- Упрощена структура для лучшей читаемости
- Детализация процесса переноса вынесена в отдельный подпроцесс
- Использует `partition` для группировки связанных операций

### 4. **table-migration-subprocess.puml**
Детальная диаграмма подпроцесса "Перенос таблиц".

**Содержит:**
- Анализ объектов MS SQL Server
- Определение типа объекта и заполнение соответствующих таблиц
- Основной цикл миграции с обработкой ошибок
- Проверка завершения всех объектов
- Детализированная логика процесса переноса

**Примечание:** 
- Детализирует подпроцесс, упомянутый в основной диаграмме
- Содержит полную логику миграции объектов
- Используется для детального понимания процесса переноса

### 5. **table-migration-detailed-process.puml**
Упрощенная диаграмма процесса переноса таблиц.

**Содержит:**
- Создание запроса для получения списка таблиц исходной БД
- Простая структура с одной задачей между началом и окончанием

**Примечание:** 
- Упрощенная версия для базового понимания процесса
- Содержит только ключевую задачу подготовки к миграции
- Используется как отправная точка для детализации



### 6. **migration-reporting-system.puml**
Схема системы отчетности и представлений.

**Содержит:**
- Представления для анализа прогресса: `migration_overview`
- Детальные представления: `table_migration_details`, `view_migration_details`
- Статистические представления: `migration_statistics`
- Представления для анализа ошибок: `error_summary`
- Связи представлений с таблицами

**Примечание:** Исправлена ошибка с макросом VIEW - теперь используется правильный синтаксис PlantUML.

### 7. **migration-reporting-system-simple.puml**
Альтернативная версия схемы отчетности без использования макросов.

**Содержит:**
- Те же представления, что и в основной схеме
- Использует стандартный синтаксис PlantUML
- Повышенная совместимость с различными версиями PlantUML

## 🎯 Ключевые особенности схемы

### **Наследование таблиц**
- **mssql_objects** - родительская таблица с общими полями
- Дочерние таблицы наследуют структуру и ограничения
- Специфичные поля для каждого типа объекта

### **Типы объектов**
- **Таблицы:** размер, количество строк, наличие ключей
- **Представления:** определение, обновляемость, зависимости
- **Функции:** тип возврата, параметры, детерминированность
- **Хранимые процедуры:** определение, параметры, шифрование

### **Отслеживание миграции**
- Статусы: pending, completed, failed, skipped
- Даты миграции и ошибки
- Сравнение данных между БД

### **Система отчетности**
- Представления для анализа прогресса
- Детальная статистика по типам объектов
- Сводные отчеты и анализ ошибок

## 📊 Структура данных

### **Основные таблицы**
- `migration_tasks` - задачи миграции
- `mssql_objects` - базовые объекты MS SQL

- `error_summary` - сводка ошибок

### **Функции**
- `add_mssql_*()` - добавление объектов
- `update_migration_status()` - обновление статусов
- `get_migration_progress()` - получение прогресса
