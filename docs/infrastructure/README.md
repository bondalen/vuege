# 🔧 Инфраструктурная документация проекта Vuege

Эта папка содержит документацию по инфраструктуре проекта, включая логи, отчеты и технические документы.

## 📁 Структура

```
docs/infrastructure/
├── README.md           # Этот файл
├── logs/               # Логи выполнения скриптов
│   ├── migration/      # Логи миграции базы данных

│   └── maintenance/    # Логи обслуживания
└── reports/            # Отчеты и аналитика
    ├── migration/      # Отчеты миграции
    ├── performance/    # Отчеты производительности
    └── security/       # Отчеты безопасности
```

## 📊 Логи (`logs/`)

### Миграция базы данных
Логи процесса миграции схемы AGS из SQL Server в PostgreSQL:

- **Основные логи миграции:**
  - `ags-schema-migration.log` - Основной лог миграции схемы AGS
  - `migrate-only-ags-schema.log` - Лог основного скрипта миграции
  - `continue-ags-migration.log` - Лог продолжения миграции
  - `final-migration.log` - Лог финальной миграции
  - `fixed-migration.log` - Лог исправленной миграции

- **Логи DBHub:**
  - `dbhub-real-migration.log` - Лог реальной миграции через DBHub
  - `dbhub-migration-execution.log` - Лог выполнения миграции DBHub
  - `dbhub-group1-docker-migration.log` - Лог миграции группы 1 в Docker
  - `dbhub-group1-fixed-migration.log` - Лог исправленной миграции группы 1

- **Логи исправлений:**
  - `fix-group1-structure.log` - Лог исправления структуры группы 1
  - `fix-column-case-*.log` - Логи исправления регистра колонок
  - `fix-uuid-*.log` - Логи исправления UUID типов
  - `fix-table-names-*.log` - Логи исправления имен таблиц
  - `fix-remaining-*.log` - Логи исправления оставшихся таблиц
  - `run-all-fixes-*.log` - Логи запуска всех исправлений

- **Дополнительные логи:**
  - `migrate-cn-simple.log` - Лог простой миграции CN
  - `migrate-group1-data-improved.log` - Лог улучшенной миграции данных группы 1
  - `real-migration-with-data.log` - Лог реальной миграции с данными

## 🎯 Назначение

### Для разработчиков
- **Анализ проблем** - изучение логов для диагностики ошибок
- **Отслеживание прогресса** - мониторинг выполнения процессов
- **Оптимизация** - анализ производительности и улучшение процессов

### Для DevOps/Инфраструктуры
- **Мониторинг** - отслеживание состояния систем
- **Диагностика** - выявление и устранение проблем
- **Документирование** - сохранение истории изменений

### Для аналитики
- **Метрики** - сбор данных о производительности
- **Отчеты** - анализ результатов выполнения задач
- **Тренды** - отслеживание изменений во времени

## 📝 Правила работы с логами

### Именование файлов
- **Формат**: `{процесс}-{дата}_{время}.log`
- **Пример**: `fix-column-case-20250830_141210.log`

### Структура логов
- **Заголовок** - информация о процессе и времени запуска
- **Прогресс** - пошаговое выполнение с временными метками
- **Результаты** - итоговые показатели и статус
- **Ошибки** - детальная информация об ошибках

### Хранение
- **Активные логи** - в соответствующих папках по типу процесса
- **Архивирование** - старые логи архивируются по месяцам
- **Очистка** - логи старше 6 месяцев удаляются
