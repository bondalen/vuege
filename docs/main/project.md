## Архитектура системы

### Backend архитектура

**Spring Boot 3.4.5** с реактивной архитектурой:
- **GraphQL API** - основной интерфейс для клиентов
- **R2DBC** - реактивный доступ к PostgreSQL
- **Liquibase** - управление миграциями БД
- **Spring Security** - аутентификация и авторизация
- **Spring Boot Actuator** - мониторинг и метрики

### Frontend архитектура

**Vue.js 3.4.21** с современным стеком:
- **Quasar Framework 2.16.1** - UI библиотека
- **TypeScript 5.4.0** - типизация
- **TanStack Router 1.16.0** - роутинг
- **Apollo Client 3.13.5** - GraphQL клиент
- **Pinia** - управление состоянием

### База данных

**PostgreSQL 16** с расширенной функциональностью:
- **PostGIS** - ГИС-функциональность (готово к активации)
- **Liquibase** - управление схемой
- **Тестовые данные** - исторические примеры
- **Индексы** - оптимизация производительности
