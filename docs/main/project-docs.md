## 📊 Система контроля миграции

### Обязательные процедуры

#### 1. Инициализация системы контроля
При начале нового этапа миграции:
```bash
# Создание схемы контроля
python3 src/infrastructure/scripts/create-migration-control-schema.py

# Заполнение данными
python3 src/infrastructure/scripts/populate-migration-control-tables.py
```

#### 2. Ежедневный мониторинг
```bash
# Просмотр прогресса
python3 src/infrastructure/scripts/view-migration-progress.py
```

#### 3. Обновление статусов
При выполнении миграции объектов:
- Обновление статуса в таблице `migration_control.specific_objects`
- Запись ошибок в поле `error_message`
- Установка даты миграции в `migration_date`

### Таблицы контроля миграции

#### `migration_control.objects`
Основная таблица типов объектов:
- `id` - Уникальный идентификатор
- `has_in_mssql` - Наличие в MS SQL Server
- `has_in_postgres` - Наличие в PostgreSQL
- `object_type` - Тип объекта
- `name_in_mssql` - Наименование в MS SQL Server
- `name_in_postgres` - Наименование в PostgreSQL

#### `migration_control.specific_objects`
Таблица конкретных объектов:
- `id` - Уникальный идентификатор
- `object_id` - Ссылка на таблицу objects
- `name_in_mssql` - Наименование в MS SQL Server
- `name_in_postgres` - Наименование в PostgreSQL
- `migration_status` - Статус миграции (pending, completed, failed)
- `migration_date` - Дата миграции
- `error_message` - Сообщение об ошибке

### Представления для мониторинга

#### `migration_control.migration_progress`
Отображает прогресс миграции по типам объектов с процентным соотношением.

#### `migration_control.detailed_progress`
Детальный просмотр всех объектов с их статусами миграции.
